## 🔒 Conformidade com a Privacidade (LGPD)

Em consonância com as diretrizes da **Lei Geral de Proteção de Dados (Lei nº 13.709/2018)** e o princípio da **Minimização de Dados**, todos os documentos acadêmicos contidos neste diretório foram rigorosamente auditados para omitir dados pessoais sensíveis e números de identificação acadêmica (RA/RGM), preservando a integridade das informações públicas do repositório.
